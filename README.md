Student Performance Analyzer

About the Project:

Student Performance Analyzer is a Python-based project that manages student records and analyzes their academic performance. It calculates total marks, percentage, grades, pass/fail status, and identifies the topper.

Features:

- Add student records
- Store marks for five subjects
- Calculate total marks and percentage
- Assign grades based on percentage
- Check pass/fail status
- View all student records
- Search students by roll number
- Identify the topper
- Save student records in a JSON file

Technologies Used:

- Python
- JSON
- File Handling

Subjects:

- Python
- DBMS
- Machine Learning
- Maths
- DSA

How to Run:

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python student_performance.py

Project Structure:

- "student_performance.py" — Main Python program
- "students.json" — Local file used to store student records
